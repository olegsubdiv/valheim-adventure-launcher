# Adventure Launcher

Общаться по-русски, интерфейс приложения на английском. Это отдельный Git-репозиторий
клиентского launcher внутри проекта Valheim. Читать ../AGENTS.md и ../HANDOFF.md.
Миры, сервер/Baka, игровые настройки и живые профили не менять ради разработки.

Никогда не коммитить .private, ключи подписи, OAuth, пароли, пакеты сторонних модов
или локальные абсолютные пути из deployment.json. Репозиторий содержит только наш
код и публичные метаданные релиза. Тяжёлые тесты — синтетические, без чужих данных.
Не публиковать Nexus-архивы, у которых запрещено зеркалирование.

Используется .NET10 LTS SDK10.0.402, изолированно в .tools/dotnet. Подпись manifest:
ECDSA P-256/SHA256 DER; подписываются точные UTF-8 bytes payload, public key pinned.
Обычные обновления не должны перескачивать/копировать неизменившийся HD. При
проверках использовать отдельные fixtures, не запускать игру. Не обещать рабочую
установку/автообновления без сборки и проверки результата.

20октября пользователь прямо поручил разместить HD и Badger на своём Google Drive
для компании, затем выбрал зашифрованные ссылки в публичном GitHub с секреткой
в launcher. Это заменяет прежнее решение о только ручном импорте для этого канала.
Никогда не коммитить plaintext URLs, company-code.txt или upload receipts; только
AES-GCM ciphertext. Расшифрованные источники требуют подписи и совпадающих pins.
Код доступа не равен Google-авторизации; без него ручной Nexus import остаётся.
